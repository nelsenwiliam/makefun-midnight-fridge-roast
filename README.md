A tiny pure-stdlib Python program that writes one roast of a smart fridge that locks itself after midnight — a single line, 95 characters — to `/output/entry.txt`. The roast targets the fridge's petty midnight rule itself: it flashes ACCESS DENIED at its own owner, like they're breaking into their own leftovers.

## Run it

```sh
python3 main.py
```
